## 五、明确声明边界（不达标 / 不可宣称项）

1. **不宣称训练准确率。** 本项目无数据集标注与模型训练流程，识别能力来自调用云端成熟视觉大模型；
   因此**不得**在答辩材料中出现「识别准确率 99% / 95%」等训练指标。
   可陈述的客观指标为：**受控测试集上的规则命中率**与**实测响应耗时**。
2. **本地可解释引擎是规则引擎**，不是神经网络，定位为「云端兜底 + 可解释性素材」。
3. **未使用 Nuxt / TypeScript / Storybook / TanStack Query**：均为推荐项（非强制），本项目场景下迁移收益低于成本，
   已在核查表中标注为「可接受」，答辩时可主动说明技术选型理由。
4. **用户无法由 AI 代做的提交材料**：报名信息、演示视频录制、作品说明书签章、原创承诺书等。
