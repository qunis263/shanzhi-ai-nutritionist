# 社会价值试点说明

## 目标

“试点与成效”模块用于把社会价值从文字主张变为可重复、可审计的真实使用证据。系统不预填参与人数、留存率或改善结果；所有指标均由匿名参与、问卷提交和产品行为事件产生。

## 使用流程

```text
创建试点批次 → 分享邀请码 → 匿名授权加入 → 使用前问卷
→ 食物识别 / 饮食记录 / AI 对话 / 7 天微干预
→ 使用后问卷 → 社会价值运营看板
```

默认示范批次邀请码为 `SHANZHI2026`，仅用于本地流程验收。正式试点应在页面中创建独立批次，并为每所学校或每轮活动使用不同邀请码。

## 匿名数据范围

系统保存：

- 随机生成的匿名参与编号
- 年龄段、参与身份、健康目标和饮食困扰
- 使用前与使用后量表
- 食物识别、饮食记录、AI 对话和微干预等事件类型
- 微干预打卡时的匿名营养指标

系统不保存姓名、手机号、学号、精确地址或完整聊天内容。当前实现使用浏览器 `localStorage`，适合省赛演示和小规模单机试点；多人正式试点需要接入具备权限控制和数据加密的服务端。

## 指标口径

| 指标 | 计算方式 |
| --- | --- |
| 微干预采纳率 | 创建微干预的参与者 / 匿名参与者 |
| 7 天完成率 | 完成微干预的参与者 / 匿名参与者 |
| 人均饮食记录 | 饮食记录事件数 / 匿名参与者 |
| 付费意愿 | 后测选择非免费价格的人数 / 完成后测人数 |
| 实际评分变化 | 同一参与者最后一次打卡评分 - 第一次打卡评分 |

有效参与者少于 5 人时，页面显示“样本不足”，相关数字只用于功能验收，不用于宣称效果。

## 当前限制

- 浏览器本地数据不能跨设备聚合。
- 7 天完成率是产品行为指标，不代表医学效果。
- 前后测属于用户自评，正式研究需补充问卷信效度和伦理审查。
- 市场规模、付费意愿和竞品效果仍需通过真实试点验证，不能用演示数据替代。
